# SkanBay_StormReconstruction
Codes and raw data needed to run analysis and produce figures from McKeon et al. (2026), North Pacific extreme storms reconstructed with a novel approach to estimating storm frequency and uncertainty



Code JPC05C_Frequency.py contains all analysis related to sediment core processing, data analysis, and storm frequency calculation. 

Data to run this code is in the core_data and Witter_2019_Comparison folders. 



Code MetData.py contains all analysis related to meteorological and oceanographic observations. 

Data to run this code is in the MetData folder.



Code JPCC_PlumCode.R is the code used to run the rPlum age model. 

Data to run this code is in the Data_for_rPlum folder.



Code JPC05_XRF.m is the code used to plot the XRF data.

Data to run this code is in the XRF_Data folder.
